DESIGN DECISIONS
═══════════════════════════════════════════════════════════════════════════════

1. ADMIN-CURATED TAGS ONLY
   - No user-generated tags in Phase 1
   - createdBy field tracks which admin created the tag
   - Ensures quality and consistency of tag taxonomy

2. COLOR FIELD
   - Defaults to Quiet Depth text secondary color (#6E6E73)
   - Allows future UI customization per tag
   - Stored as hex string for simplicity

3. JUNCTION TABLE PATTERN
   - recordTags uses proper junction table (not JSON array)
   - Follows AGENTS.md constraint: "JSON 배열로 M:N 관계 저장 금지"
   - Enables efficient querying and filtering

4. TIMESTAMPS
   - Uses unixepoch() for consistency with existing schema
   - created_at: when tag was created
   - updated_at: when tag was last modified

5. UNIQUE CONSTRAINTS
   - name: unique across all tags (prevents duplicates)
   - slug: unique across all tags (URL-safe identifier)
   - Composite PK on recordTags: prevents duplicate tag assignments
