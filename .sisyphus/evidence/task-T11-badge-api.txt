# T11: API, Inbox, and GlobalNav Unread Badge Correctness

## Task Summary
Fix the `/api/notifications` route to use COUNT-based unread queries, add canonical `recordSlug` to notification payloads, and ensure GlobalNav badge polling works correctly.

## Changes Made

### 1. notifications.server.ts - COUNT-based getUnreadCount()

**Before:**
```typescript
export async function getUnreadCount(d1: D1Database, recipientId: string) {
  const database = db(d1);
  const result = await database
    .select({ id: notifications.id })
    .from(notifications)
    .where(and(eq(notifications.recipientId, recipientId), eq(notifications.isRead, false)));

  return result.length;
}
```

**After:**
```typescript
import { and, count, desc, eq } from "drizzle-orm";

export async function getUnreadCount(d1: D1Database, recipientId: string) {
  const database = db(d1);
  const result = await database
    .select({ count: count() })
    .from(notifications)
    .where(and(eq(notifications.recipientId, recipientId), eq(notifications.isRead, false)));

  return result[0]?.count ?? 0;
}
```

**Impact:** Uses SQL COUNT() instead of fetching all rows and counting in JS. More efficient for large notification counts.

### 2. /api/notifications.tsx - Added recordSlug to payload

**Before:** Notifications only included `recordId`, requiring navigation to `/logs/${recordId}` which would fail.

**After:**
```typescript
const [notifs, unreadCount] = await Promise.all([
  database
    .select({
      id: notifications.id,
      type: notifications.type,
      title: notifications.title,
      content: notifications.content,
      recordId: notifications.recordId,
      recordSlug: records.slug,  // NEW: Joined from records table
      questionId: notifications.questionId,
      isRead: notifications.isRead,
      createdAt: notifications.createdAt,
    })
    .from(notifications)
    .leftJoin(records, eq(notifications.recordId, records.id))
    .where(eq(notifications.recipientId, auth.user.id))
    .orderBy(desc(notifications.createdAt))
    .limit(8),
  getUnreadCount(context.cloudflare.env.DB, auth.user.id),
]);
```

**Impact:** API now returns canonical `recordSlug` for navigation.
