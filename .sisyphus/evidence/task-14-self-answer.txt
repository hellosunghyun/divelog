# Task 14: Self-answer 생성 UI — Evidence

## Summary
기록 작성자가 자기 기록의 질문에 답변하는 자기 답변 기능을 구현함.

## Files Created

### 1. app/components/SelfAnswerCard.tsx
- "자기 답변" 뱃지 (배경: bg-mist-blue, 텍스트: text-ocean-blue)
- Editorial card 스타일 (말풍선/채팅 버블 디자인 사용하지 않음)
- 타임스탬프 표시 (unixepoch → readable date)
- data-testid="self-answer-card" 추가

### 2. app/db/queries/selfAnswers.server.ts
- createSelfAnswer(d1, authorId, { questionId, content })
- getSelfAnswersByQuestion(d1, questionId)
- getSelfAnswersByRecord(d1, recordId) - record의 모든 질문에 대한 self-answer 조회

#### Action Changes
- "create_self_answer" intent 추가

#### UI Changes
