# Task 13: Search sentences tab panel rendering (M-5)

## Summary
Fixed the missing sentences tab panel in the search page. The tab label "문장" existed but there was no corresponding panel to render the sentence results.

## Changes Made

### File: app/routes/public/search.tsx

1. **Added import** (line 10):
   - `import HighlightedSentenceCard from "~/components/HighlightedSentenceCard";`

2. **Added sentences tab panel** (lines 241-255):
   - Added a new section that renders when tab is "all" or "sentences" and results.sentences.length > 0
   - Uses a 2-column grid layout (consistent with other result sections)
   - Maps over `results.sentences` and renders `HighlightedSentenceCard` for each sentence
   - Passes `sentence` prop from the loaded data

## Technical Details

- The loader already fetched `foundSentences` (lines 76-89) and included it in `results.sentences`
- `HighlightedSentenceCard` expects:
  - `sentence: { id, content, reason? }` - provided from loader
  - `savedBy?: { displayName, slug }` - optional, not provided
  - `record?: { slug, title }` - optional, not provided
- Since `savedBy` and `record` are optional props, the component renders correctly with just the sentence data
