## 주요 구현 내용

### CalendarViewProps
```typescript
type CalendarViewProps = {
  records: RecordItem[];
  month: string; // "YYYY-MM" 형식
};
```

### CalendarCell 컴포넌트
- 현재 월이 아닌 날짜: opacity-50, bg-surface-secondary/30
- 오늘 날짜: bg-ocean-blue text-white rounded-full w-6 h-6
- 레코드 dot: 최대 3개 표시, 초과 시 "+N" 텍스트

### 데스크톱 vs 모바일 동작
- 데스크톱 (md+): Popover로 호버 시 레코드 목록 표시
- 모바일 (< md): 클릭 시 캘린더 아래에 레코드 목록 확장

### 월 네비게이션
- `useNavigate` + `useSearchParams`로 URL param 변경
- prevMonth/nextMonth: month를 1달 앞뒤로 → `?month=YYYY-MM`
