# T21: 기록 상세 페이지에서 연결된 기록(linked records) 양방향 표시 개선

## 완료 항목

### 1. `app/db/queries/records.server.ts` 수정
- `getLinkedRecords(d1, recordId, linkedRecordId)` 함수 추가
- 양방향 쿼리 구현:
  - **outgoing**: 이 기록이 참조하는 기록 (linkedRecordId로 조회)
  - **incoming**: 이 기록을 참조하는 기록들 (linkedRecordId = recordId인 기록들)
- `LinkedRecordDirection` 타입 정의 ("outgoing" | "incoming")
- `LinkedRecord` 인터페이스에 direction 필드 포함

### 2. `app/routes/_public.logs.$recordSlug.tsx` 수정
- `getLinkedRecords` import 추가
- SceneCard 컴포넌트 import 추가
- 기존 batch 쿼리에서 linkedRecords 제거
- loader에서 `getLinkedRecords` 호출로 변경
- UI에서 SceneCard 컴포넌트 사용
- 방향 표시 뱃지 추가 ("참조" / "역참조")

### 3. UI 개선
- SceneCard 컴포넌트로 연결된 기록 표시
- contentSnippet prop으로 100자 미리보기 제공
- 우측 상단에 방향 뱃지 표시:
  - "참조": 이 기록이 가리키는 기록
  - "역참조": 이 기록을 가리키는 기록
- 2열 그리드 레이아웃 (md 이상)
