## Implementation Details

### Query Pattern (Drizzle ORM):
```typescript
const allNotifs = await database
  .select({
    id: notifications.id,
    type: notifications.type,
    title: notifications.title,
    content: notifications.content,
    recordId: notifications.recordId,
    recordSlug: records.slug,  // ← New field
    questionId: notifications.questionId,
    isRead: notifications.isRead,
    createdAt: notifications.createdAt,
  })
  .from(notifications)
  .leftJoin(records, eq(notifications.recordId, records.id))  // ← New JOIN
  .where(eq(notifications.recipientId, auth.user.id))
  .orderBy(desc(notifications.createdAt))
  .limit(50);
```
