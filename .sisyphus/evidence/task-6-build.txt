## Features Implemented

1. **Markdown Shortcuts**:
   - Cmd/Ctrl + B: Wraps selection with `**` for bold
   - Cmd/Ctrl + I: Wraps selection with `*` for italic
   - Cmd/Ctrl + K: Inserts `[text](url)` link template with url selected

2. **Character Counter**:
   - Shows `{count} / 50,000` in bottom-right corner
   - Warning color at 80%+ (var(--color-warning))
   - Error color at 100% (var(--color-error))

3. **Auto Height Adjustment**:
   - Min height: 6rem (~4 lines)
   - Max height: 60vh
   - Adjusts on every content change

4. **Keyboard Shortcut Hints**:
   - Shows ⌘B, ⌘I, ⌘K hints when focused
   - Uses Korean labels: 굵게, 기울임, 링크

5. **Accessibility**:
   - Unique IDs based on name prop
   - aria-describedby links to char count or error
   - aria-live="polite" for char count updates
   - role="alert" for error messages
