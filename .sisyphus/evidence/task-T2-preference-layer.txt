## Implementation Summary

### Exports
1. **NOTIFICATION_TYPES** (const array)
   - Values: ["response", "mention", "participant_added", "reminder", "reread_reminder"]
   - Type: readonly array matching NotificationType union

2. **NotificationType** (type)
   - Union of all valid notification types
   - Derived from NOTIFICATION_TYPES array

3. **getNotificationPreferences(d1, learnerId)**
   - Returns: Record<NotificationType, boolean>
   - Default behavior: All types default to true (enabled) if not found in DB
   - Query: SELECT type, enabled FROM notification_preferences WHERE learnerId = ?

4. **upsertNotificationPreferences(d1, learnerId, preferences)**
   - Input: Partial<Record<NotificationType, boolean>>
   - Behavior: INSERT OR REPLACE with UNIQUE constraint on (learnerId, type)
   - Updates: enabled, updatedAt fields

5. **isNotificationTypeEnabled(d1, learnerId, type)**
   - Returns: boolean
   - Default: true if preference not found

6. **resetNotificationPreferences(d1, learnerId)**
   - Deletes all preferences for learner (resets to defaults)
