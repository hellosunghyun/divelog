## Implementation Details

### Before (2 sequential queries):
1. SELECT * FROM tags ORDER BY name
2. SELECT tagId, COUNT(*) FROM record_tags GROUP BY tagId
3. Map results in JavaScript

### After (1 LEFT JOIN + GROUP BY):
SELECT 
  tags.*,
  COUNT(record_tags.tag_id) as usageCount
FROM tags
LEFT JOIN record_tags ON tags.id = record_tags.tag_id
GROUP BY tags.id
ORDER BY tags.name
