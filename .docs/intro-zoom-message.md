# DiveLog 소개 — Zoom 채팅 메시지

> 아래 내용을 Zoom 채팅에 붙여넣기용으로 작성한 것입니다.

---

**다양한 Diver들을 위한 기록 공간, DiveLog를 소개합니다.**

아카데미에서 보내는 아홉 달.
매일 배우고, 고민하고, 부딪히고, 다시 시작하죠.
그런데 그 시간이 지나면, 기억나는 건 결과물뿐인 경우가 많습니다.

DiveLog는 그 사이에 있던 **질문들, 흔들렸던 순간들, 조용히 바뀌어 간 생각들**을 남기는 공간입니다.

✍️ 한 줄 메모도, 정리 안 된 생각도, 질문 하나만 남겨도 괜찮습니다
🔒 나만 보기(Draft) / 아카데미 구성원만(Cohort) / 외부 공개(Public) — 공개 범위는 내가 정합니다
💬 좋아요·댓글 없이, 공명·질문·연결로 대화합니다
📖 기록이 쌓이면, 각자의 여정을 담은 **나만의 책**으로 만들어 보는 것도 생각 중입니다

🤝 **혼자 남기는 기록도 의미 있지만, 함께 남길수록 더 깊어집니다.**
누군가의 질문이 내 생각을 다시 열어주고, 내 기록이 다른 사람의 공명이 됩니다.
같은 시간을 지나는 사람들이 함께 기록할 때, 개인의 흔적은 **공동의 기억**이 됩니다.
노트 앱이나 블로그에는 없는, 이 공간만의 이유입니다.

📚 논문 400편 이상이 확인한 사실 — 기록은 불안과 스트레스를 줄이고, 작업기억 부담을 덜어 집중력과 창의성을 높여줍니다.
